# Brainrot Duel

## Файлы
- `index.html` — главная страница и интерфейс.
- `style.css` — тёмная тема, адаптация под телефон, выдвижная шторка.
- `script.js` — кейсы, аккаунты, баланс, инвентарь, промокод, админ-инструменты и апгрейдер.

## Запуск и GitHub Pages
Открой `index.html` в браузере. Для публикации загрузи все файлы в корень репозитория GitHub, затем Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Новые функции
- Меню открывается кнопкой с тремя полосками в верхней панели. В нём есть ссылки на кейсы, инвентарь и промокод, а также апгрейдер.
- Апгрейдер позволяет выбрать Brainrot из инвентаря и повысить его уровень за B. Стоимость растёт с каждым уровнем, а стоимость продажи Brainrot увеличивается на 50% при каждом улучшении.
- Код `ADMINPANEL666SECRET` показывает админ-панель. Админ может выдать текущему вошедшему аккаунту до 500 000 000 B за одно действие или выдать любой Brainrot из трёх кейсов.

## ВАЖНО — безопасность
Это статическая демо-версия для GitHub Pages. Код админ-активации находится в `script.js`, поэтому любой посетитель технически может его посмотреть. Админ-операции выполняются только в браузере и влияют на локальные данные. Для настоящей защиты, общей базы игроков, безопасной выдачи валюты/предметов и лимитов нужен сервер с авторизацией и базой данных. Не используй эту клиентскую панель как настоящую админ-защиту.

Аккаунты и прогресс хранятся в localStorage браузера. Пароли не защищены сервером и данные не синхронизируются между устройствами.
