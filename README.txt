# Brainrot Duel

## Файлы
- `index.html` — главная страница.
- `style.css` — тёмное оформление и адаптация под телефон.
- `script.js` — кейсы, регистрация/вход, баланс B, инвентарь, продажа предметов, промокод и таймер Free Case.

## Запуск
Открой `index.html` в браузере. Для публикации на GitHub Pages загрузи все три файла в корень репозитория и выбери Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Важно
Это frontend-демо: аккаунты, баланс и инвентарь хранятся в localStorage браузера. Пароли не защищены сервером, данные не синхронизируются между устройствами. Промокод `RELEASE26` выдаёт 150 B один раз на аккаунт в этом браузере; лимит в 700 активаций нельзя надёжно обеспечить без серверной базы и атомарного счётчика. Для настоящего публичного проекта потребуется backend и база данных.

В таблицах кейсов сохранены указанные шансы. Поскольку суммы шансов в кейсах превышают 100%, они используются как относительные веса и нормализуются при выборе награды.
